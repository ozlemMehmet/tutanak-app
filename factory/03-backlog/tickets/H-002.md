## Kapsam
`apps/web/src` ve `apps/api/src` altindaki kullaniciya donuk tum dizeler (buton/etiket
metinleri, bos durum metinleri, hata mesajlari, API hata govdeleri) ASCII'ye katlanmis
Turkce olarak yazilmis (`ş ğ ı ö ü ç` karakterlerinin hicbiri kullanilmamis). Olcum:
`apps/web/src` icindeki 64 kaynak dosyanin (test/spec haric) 0'i, `apps/api/src` icindeki
99 kaynak dosyanin (test/spec haric) 0'i Turkce karakter iceriyor. Projede i18n katmani
yok (`package.json`'larda i18n/intl bagimliligi yok); duzeltme dizelerin bulundugu yerde
yapilir.

Bu ticket, kullaniciya donuk TUM dizelerin (arayuz metinleri + API hata mesajlari + PDF
etiket sabitleri) duzgun Turkce'ye cevrilmesini kapsar. PDF etiket sabitleri
(`apps/api/src/modules/pdf/report-pdf.builder.ts` icindeki `TEMPLATE_LABEL` = "Sablon: ",
`NOTE_LABEL` = "Not: ", `PHOTO_STAMP_LABEL` = "Fotograf tarihi: ", `APPROVAL_HEADING` =
"Taraf onayi", `APPROVER_LABEL` = "Onaylayan: ", `APPROVED_AT_LABEL` = "Onay tarihi: ")
BU kapsamdadir (metin duzeltmesi), ancak bu metinlerin PDF ciktisinda GORSEL olarak dogru
basilabilmesi icin H-001'in (Turkce kapsayan font) once tamamlanmis olmasi gerekir — bkz.
"Bagimli oldugu ticketlar" ve Teknik Notlar.
