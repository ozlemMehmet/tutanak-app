## Kapsam
`apps/web/Dockerfile` ve `apps/api/Dockerfile` icindeki `RUN npm ci`, bagimliliklarin
**lifecycle script'lerini** (`preinstall`/`install`/`postinstall`/`prepare`) calistirir.
Ele gecirilmis bir bagimlilik imaj derlemesi sirasinda kod calistirabilir. Bulgu kaynagi:
SonarCloud, PR #27 — "Omitting `--ignore-scripts` allows lifecycle scripts to run during
package installation".

**Bu ticket "her yere `--ignore-scripts` ekle" DEGILDIR** — API imajinda korumasiz uygulanirsa
imaj bozulur:

- `apps/api` iki NATIVE modul kullanir: `bcrypt` (^6.0.0) ve `sharp` (^0.35.3). Ikisi de
  ikili dosyalarini kurulum script'leriyle derler/indirir; script'ler kapatilirsa modul
  yuklenemez ve uygulama ACILMAZ.
- Kok `package.json`'da `prepare: husky || true` vardir; imaj icinde atlanmasi ZARARSIZDIR
  (git kancasi uretim imajinda gereksizdir).

Bu yuzden dogru cozum katmanlidir: script'ler kapatilir, native moduller ACIKCA ve
denetlenebilir bicimde yeniden derlenir (`npm rebuild <modul>` veya esdegeri).

## Kabul Kriterleri (test edilebilir)
- [ ] `apps/web/Dockerfile` bagimlilik kurulumunu `--ignore-scripts` ile yapar; web uretim imaji derlenir ve `GET /` 200 doner (mevcut CSP + HSTS + nosniff + Referrer-Policy basliklari korunur).
- [ ] `apps/api/Dockerfile` bagimlilik kurulumunu `--ignore-scripts` ile yapar; ardindan `bcrypt` ve `sharp` acikca yeniden derlenir/kurulur ve bu adim Dockerfile'da gerekcesiyle yorumlanir.
- [ ] API uretim imaji derlenip ayaga kaldirildiginda `GET /health` 200 `{"status":"ok"}` doner (yani native moduller gercekten yuklenebiliyor).
- [ ] Native modullerin FIILEN calistigi kanitlanir: uretim imaji uzerinde (a) kayit/giris akisi calisir (`bcrypt`), (b) fotograf yukleme 201 doner ve depolanan gorselin uzun kenari <= 1600 px'tir (`sharp`, T-026 davranisi korunur).
- [ ] `docker compose -f docker-compose.e2e.yml up --build` duman testi yigini bastan sona calisir; T-026'nin perf duzeltmesi ve T-024'un guvenlik basliklari bozulmaz.
- [ ] `npm run test`, `npm run test:e2e`, `lint`, `typecheck` temiz kalir.

## Kapsam DISI
- Yerel gelistirme akisini (`docker-compose.yml` `target: dev`, host `npm ci`) degistirmek — kanca ve script'ler gelistiricide calismaya devam eder.
- `docker-compose.e2e.yml` icindeki `POSTGRES_PASSWORD: tutanak` degeri: SonarCloud bunu "gomulu sifre" olarak isaretliyor ancak bu, `down -v` ile silinen GECICI duman testi yigininin fixture'idir; uretim yolu (`factory/10-release/runbook.md` §1 compose) sifreyi `${POSTGRES_PASSWORD}` ile `.env`'den alir. **Degistirilmeyecek**; yalnizca dosyaya bu kararin gerekcesini yazan bir yorum eklenmesi yeterlidir.
- Imajlari root olmayan kullaniciyla calistirmak (guvenlik denetimi S-06, LOW) — ayri ele alinir.

## Teknik Notlar (varsa)
- `npm ci --ignore-scripts` sonrasi `npm rebuild bcrypt sharp` calistirmak yaygin kalibdir; alternatif olarak `sharp` icin platform ikililerinin `optionalDependencies` ile geldigi surum kullanilabilir — hangisi secilirse devlog'da gerekcelendirilmelidir.
- Cok asamali imajda `deps` katmani degisecegi icin katman onbellegi bir kez gecersizlesir; bu beklenen ve tek seferliktir.
